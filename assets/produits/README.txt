Dossier pour les photos des produits.

Placez vos images de produits dans ce dossier.
Utilisez des formats courants comme JPG, PNG ou WebP.
Nominez vos fichiers de manière descriptive, par exemple: console-retro.png, figurine-zeld.jpg.

Dans le code HTML, référencez l'image ainsi :
    <img src="assets/produits/votre-image.jpg" alt="Description du produit">

Les dimensions recommandées sont de 400x400 pixels pour une bonne présentation, mais le modèle s'adaptera.
